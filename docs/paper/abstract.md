# Abstract — scientific-edited working draft

Machine-facing dictionary services can expose structured lexical data while still leaving a basic auditability question unanswered: which exact released value supports a returned claim, and can that publication state later be reconstructed and checked? We present a hybrid **lexico-conceptographic pipeline** that couples structured lexical representation with two integrity layers. At the output level, every supported atomic claim carries a deterministic `evidence_id` bound to a release, canonical entry commitment, and exact JSON Pointer. At the release level, the complete entry set is committed by deterministic RFC 8785/JCS serialization, SHA-256 content hashes, a versioned Merkle construction, and an external release-manifest digest. The pilot uses 25 structurally heterogeneous entries from the twenty-volume *Dictionary of the Ukrainian Language* (SUM-20), producing 840 Evidence Records. A deterministic API evaluation yielded EC=1.000, ERS=1.000, RR=1.000, and FRR=0.000 across 50 answerable and 13 evidence-insufficient queries. A frozen 45-case evidence-corruption profile exposed incomplete runtime enforcement (EVDR=0.5333); after contract-aligned hardening, the unchanged fault set yielded EVDR=1.000. P3 then materialized release `sum20-hist-ap-pilot-r001`; a separate frozen 30-case release-tamper profile yielded TDR=1.000. The novelty is not a new lexical standard, hash function, Merkle algorithm, or blockchain protocol, but a publication contract that joins **field-level release-bound evidence, evidence-aware refusal, deterministic release commitments, versioned fault injection, and an explicit local-versus-external trust boundary**. The resulting compact release commitment is blockchain-ready for later external anchoring; no blockchain deployment is claimed.
